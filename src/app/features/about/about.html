About this app

This courses app is my homework from the Angular Fundamentals course of EPAM, in 2021. The course had five modules, and from the second one on the same app grew: components first, then forms, directives and pipes, then routing and services, then an NgRx store. EPAM gave the task sheets, a template project and a NestJS backend to run on localhost.

My code from the course got lost, so in 2026 I wrote the app again from the task sheets (a slightly newer version of them, the one I still have), with Angular 22: standalone components, signals, functional guards and interceptors, NgRx with functional effects. The backend is my own, the same one my React Fundamentals app uses: a small API without a framework that runs as a Bun server on my machine and, on this site, inside your browser. It keeps its data in your browser's localStorage, so feel free to add, edit and delete; Reset demo data at the bottom brings the starting courses back.
