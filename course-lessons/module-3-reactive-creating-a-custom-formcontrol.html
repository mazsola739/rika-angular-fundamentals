Most apps require some sort of user input through forms. Html provides some form inputs like textfields, textareas, checkboxes, buttons and so on. Some apps require additional input types, for example: a datepicker, a userpicker or something like a counter field with a minus and plus button. We could add additional code to the form it self to make it working, but this isn’t an optional approach, we should prevent redundancy and make a reusable component. In this post I’ll use reactive forms to handle the user input. I’ll show you how to create a custom input field using Angular components and the ControlValueAccessor interface. In this example we will create a simple form to order drinks, this form contains a custom input that can be increased/decreased using a plus/minus button.

We’re going to use the ReactiveFormsModule , you can add it to the imports section of the app.module.ts .

This form contains a few inputs to submit an order. At the bottom of our page we can use the json pipe to see what values our form contains. We have to update our place-order.component.ts file as well, in this file we added a factory method createForm which contains a definition of our form fields.

place-order.component.ts

import { Component, OnInit } from "@angular/core";
import { FormGroup, FormControl } from "@angular/forms";

@Component({
 selector: "app-root",
 templateUrl: "./app.component.html",
 styleUrls: ["./app.component.scss"],
})
export class AppComponent implements OnInit {
 form: FormGroup;

 ngOnInit(): void {
   this.form = this.createForm();
 }

 createForm() {
   return new FormGroup({
     name: new FormControl(""),
     white_wine: new FormControl(0),
     red_wine: new FormControl(0),
     beer: new FormControl(0),
   });
 }
}

Using this form works fine, when typing you can see the json changing on the bottom of the page. Currently, we have tree number fields for taking our order. This is fine, but I would like users to press on a plus/minus button to increase/decrease the value of the input field.

Create a custom component

Let’s start by generating a custom component using Angular CLI.

First, let add an input to show a number and two buttons, one for decrease and one for increase.

counter-input.component.html

<button class="modify decrease" (click)="decrease()">-</button>
<input type="text" readonly [value]="value" />
<button class="modify increase" (click)="increase()">+</button>

As you can see we created two methods, one for increase and one for decrease. Let’s create the counter-input.component.ts code now.

counter-input.component.ts

import { Component, Input } from "@angular/core";

@Component({
 selector: "app-counter-input",
 templateUrl: "./counter-input.component.html",
 styleUrls: ["./counter-input.component.scss"],
})
export class CounterInputComponent {
 @Input() min: number;
 @Input() max: number;

 value = 0;

 increase(): void {
   if (typeof this.max === "undefined" || this.value < this.max) {
     this.value++;
   }
 }

 decrease(): void {
   if (typeof this.min === "undefined" || this.value > this.min) {
     this.value--;
   }
 }
}

Implement the ControlValueAccessor

A ControlValueAccessor allows us to use our custom component as a form input. This allows us to add additional attributes to our component like FormControlName. The ControlValueAccessor will require us to implement a couple of methods to our counter-input.component.ts class.

interface ControlValueAccessor {
  writeValue(obj: any): void
  registerOnChange(fn: any): void
  registerOnTouched(fn: any): void
  setDisabledState(isDisabled: boolean)?: void
}

INFO

💡 Angular describes the ControlValueAccessor as: Defines an interface that acts as a bridge between the Angular forms API and a native element in the DOM. More on docs.

In addition to the just implemented methods we have to define a few additional methods and attributes. Let’s define a method for onChange and onTouched , I’ll explain the need of those methods/attributes later on.

onChange: any = () => {};
onTouched: any = () => {};
disabled = false;

Using a FormControl in your application allows you to disable/enable your controls programmatically. FormControls register user interaction, like when a user touched a control or changed its value. Using the ControlValueAccessor interface allows u to tell our component what to do when code of a user interacts with our custom input. Let’s have a look at the newly implemented methods and let them actually do something.

First lets edit the writeValue method, by default the parameter is named obj and typed any, in our case we want this to be called value and typed number. With this method we will simply change the value of our component.

writeValue(value: number): void {
  this.value = value;
}

Now let’s register the onChange and onTouched methods as defined before. These methods can be used to tell ReactiveForms when your component is changed or touched.

registerOnChange(fn: any): void {
  this.onChange = fn;
}
registerOnTouched(fn: any): void {
  this.onTouched = fn;
}

After registering the methods we should assign the disabled attribute.

setDisabledState?(isDisabled: boolean): void {
  this.disabled = isDisabled;
}

We would like our component to emit a change event after a button is pressed, we can simply do this by calling a just registered method.

counter-input.component.ts

increase(): void {
  if (typeof this.max === 'undefined' || this.value < this.max) {
     this.value++;
     this.onChange(this.value);
  }
}
decrease(): void {
  if (typeof this.min === 'undefined' || this.value > this.min) {
     this.value--;
     this.onChange(this.value);
  }
}

After implementing all the code we need, we have to make sure that the ControlValueAccessor is provided to our component. We can do this by adding the following code to the @Component decorator.

providers: [
 {
   provide: NG_VALUE_ACCESSOR,
   useExisting: forwardRef(() => CounterInputComponent),
   multi: true,
 },
];

INFO

💡 We need to use a forwardRef here, because the CounterInputComponent is not yet defined. It will be defined later on. More information about forwardRef can be found here.

Our counter-input.component.ts file should look something like this now.

counter-input.component.ts

import { Component, Input, forwardRef } from "@angular/core";
import { ControlValueAccessor, NG_VALUE_ACCESSOR } from "@angular/forms";

@Component({
 selector: "app-counter-input",
 templateUrl: "./counter-input.component.html",
 styleUrls: ["./counter-input.component.scss"],
 providers: [
   {
     provide: NG_VALUE_ACCESSOR,
     useExisting: forwardRef(() => CounterInputComponent),
     multi: true,
   },
 ],
})
export class CounterInputComponent implements ControlValueAccessor {
 @Input() min: number;
 @Input() max: number;
 disabled = false;

 value = 0;

 onChange: any = () => {};
 onTouched: any = () => {};

 increase() {
   if (typeof this.max === "undefined") {
     this.value++;
     this.onChange(this.value);
   } else if (this.value < this.max) {
     this.value++;
     this.onChange(this.value);
   }
 }

 decrease() {
   if (typeof this.min === "undefined") {
     this.value--;
     this.onChange(this.value);
   } else if (this.value > this.min) {
     this.value--;
     this.onChange(this.value);
   }
 }

 writeValue(value: number): void {
   this.value = value;
 }

 registerOnChange(fn: any): void {
   this.onChange = fn;
 }

 registerOnTouched(fn: any): void {
   this.onTouched = fn;
 }

 setDisabledState(isDisabled: boolean): void {
   this.disabled = isDisabled;
 }
}

The only thing left for our component is updating the html. All we have to do is letting our elements know when the FormControl is disabled.

counter-input.component.html

<button class="modify decrease" (click)="decrease()" [disabled]="disabled">
 -
</button>
<input type="text" readonly [value]="value" [disabled]="disabled" />
<button class="modify increase" (click)="increase()" [disabled]="disabled">
 +
</button>
